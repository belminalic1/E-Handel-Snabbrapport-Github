# E-Handel: Snabbrapport

Snabbrapport för e-handel (jan-jun 2024) som svarar på ledningens frågor och avslutas med rekommendationer. Rapporten finns i "notebooks/report.ipynb".

## Kom igång
Python 3.13.7

(bash)
python -m venv .venv
source .venv/Scripts/activate
pip install -r requirements.txt

Öppna "notebooks/report.ipynb", välj .venv som kernel och kör Run All.
